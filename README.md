# 🍳 Recipe Website Project

A clean, modern, and user-friendly recipe website template designed to showcase delicious dishes with structured layouts and attractive visuals.

🚀 **Live Demo:** [Click here to explore the Recipe Website](https://elitasadnan.github.io/Recipe-Website-Project-/)

---

### 🛠️ Tech Stack
* **HTML5** – Semantic markup for recipes, ingredient lists, and instructions
* **CSS3** – Custom styling, modern typography, card layouts, and responsive design

---

### ✨ Features
* **Visual Meal Cards:** Well-organized presentation for meal categories and individual recipes
* **Structured Ingredients & Steps:** Easy-to-read formatting for cooking instructions
* **Fully Responsive Design:** Optimized for a seamless experience on desktop, tablet, and mobile devices
